⚙️ State 管理細節 state.js 內部機制
核心資料
_filesArray
Module-scoped 陣列，不直接 export，防止外部 mutation
[
  { id: "f-1723456789", url: "blob:...", quantity: 1 },
  { id: "ptcg-047878-abc", url: "https://...", quantity: 3 },
  ...
]
寫入操作（統一經由 _setFilesArray）
資料驗證閘道
addFiles(items) — id 重複自動重新生成
updateQuantity(id, qty) — 自動 clamp 1~99
removeFile(id) — 刪除卡片（blob revoke 由 UI 層處理）
setFilesArray(arr) — 向後相容，仍經驗證
getAndClearRejectedItems() — 取得被過濾的無效項目
🔒 所有寫入皆經型別驗證、數量 clamp、無效項目過濾
訂閱機制
subscribe(fn)
狀態變更時通知所有 subscriber，回傳取消訂閱函式
subscribe(fn) → renderPreview() → generateCarousel()
⚠️ 取消訂閱函式應在元件卸載時呼叫，避免 listener 洩漏
Mutable Export（高效讀取）
輪播動畫狀態
scrollX — 目前滾動位置
isAccelerating — 是否按住加速
loopWidth — 單份內容寬度
isHovering — 滑鼠懸浮
🎯 供 rAF loop 高效讀取，不經 getter
🎞️ 輪播動畫機制 carousel.js 內部
Step 1
generateCarousel()
展開 quantity → 平面 URL 陣列 → 每 9 張為一頁 (sheet)
內容寬度 > container → 啟用輪播 + 複製 clones × 2
否則置中靜態顯示（廢紙提醒由 refreshStatus() 負責）
Step 2
scrollAnimate()
requestAnimationFrame loop
每幀 scrollX += -0.8 (自動) 或 ±18 (按住按鈕)
Step 3
回繞機制
左邊界：scrollX <= -loopWidth×2 → +loopWidth
右邊界：scrollX >= 0 → -loopWidth
🔄 clones 數量 = 2 份（原始 + 2 份 clone = 3 倍）
